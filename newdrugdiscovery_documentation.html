The PhysicsChem
Discovery Pipeline

A unified computational framework that applies the statistical machinery of high-energy particle physics — significance testing, background modelling, Cover's theorem, anomaly detection — directly to the problem of finding new therapeutic molecules.

Primary Language Python 3.10+
Core Libraries NumPy · scikit-learn · RDKit
Paradigm Cross-domain signal extraction
Status Active development
01 — Origin

How It Started

The pipeline grew iteratively from a single observation: the mathematical challenge of finding the Higgs boson at CERN and the mathematical challenge of finding a novel drug candidate in a chemical library are structurally identical problems. Both require extracting a rare, statistically significant signal from an enormous background of irrelevant events, in a high-dimensional feature space, under strict false-positive constraints.

Development began with a virtual particle collider simulation — a clean-room reimplementation of the core statistical toolkit used at the LHC. The goal was educational: make the detector physics, background modelling, and significance-scanning machinery explicit and transparent. Over successive iterations the code grew more physically realistic: vectorised detector response, proper Breit-Wigner signal generation, luminosity-scaled Poisson histogram sampling, and a fitted background model that is actually used for significance computation (rather than the raw template histogram, which had been the longstanding bug).

Once that machinery was solid, the question became obvious: what else lives in this mathematical neighbourhood? Drug discovery was the answer. The team transposed each collider concept one-for-one into chemical space, producing a second pipeline module that reuses the same significance testing, the same anomaly detection, and the same Cover's theorem projection — but operates on molecular fingerprints and IC50 activity values instead of invariant mass spectra and transverse momentum.

"The same integral that tells you a bump in a mass spectrum is real to five sigma can tell you a molecule is significantly more active than the inactive background — to the same confidence threshold."

The collider module and the drug-discovery module now share a unified statistical core. They are documented here together because understanding one is the fastest path to understanding the other.

Design Principle

Every operation that touches arrays is fully vectorised using NumPy broadcasting. There are zero Python-level per-event loops in the hot paths. This is what makes it practical to screen 500+ molecule candidates and 100,000 background events in under 15 seconds on a laptop CPU.

03 — Mechanics

How It Works — Shared Mathematical Core

Both modules are built on four ideas borrowed directly from experimental particle physics.

1 · Cover's Theorem (High-Dimensional Projection)

Thomas Cover proved in 1965 that a classification problem which is linearly inseparable in low dimensions can become separable when projected into a sufficiently high-dimensional feature space. In the collider module this means projecting from (mass, pT) into a kernel-approximated space so that signal and background clusters separate. In the drug module it means projecting from a 256- or 2048-dimensional fingerprint into a kernel space so that active molecules separate from decoys.

Both modules use the Nystroem approximation (sklearn.kernel_approximation.Nystroem) rather than exact kernel PCA, capping memory use at O(n × k) rather than O(n²).

2 · Background Modelling & Template Fitting

The most important single design decision in either module: never compare data to data. The background must be estimated from a model, not from a second dataset of the same size. In the collider, StatisticalAnalyzer.fit_background() fits a smooth exponential+power-law curve to a large background template, then scales it to the expected luminosity. In the drug module, the Random Forest predictor is trained on all known molecules (active and inactive) so that predictions on the inactive subset provide a smooth, unbiased null distribution.

3 · Poisson Significance Testing (5σ Threshold)

For each bin in the mass spectrum (or each candidate molecule), the significance is computed as:

significance = (observed − expected_background) / sqrt(expected_background + 1)

This is the standard particle-physics local significance formula. A value ≥ 5σ corresponds to a false-positive probability of roughly 3 × 10⁻⁷ — the threshold CERN used to announce the Higgs boson discovery in 2012. The drug pipeline uses the same threshold, where "observed" is the predicted log₁₀(IC50) of a candidate and "expected background" is the null distribution derived from predicted IC50s of known inactive molecules.

4 · IsolationForest Anomaly Detection

After significance scanning identifies statistically active candidates, a second independent question is asked: does this candidate occupy novel chemical/kinematic space? IsolationForest answers this by measuring the average path length needed to isolate a point from the dataset. Short path = anomalous = novel. The pipeline correctly labels -1 as novel (the sklearn convention) and uses a percentile threshold on the raw anomaly score rather than the absolute decision boundary, which is unreliable across domains without calibration.

04 — Module A

Virtual Particle Collider

A physics-accurate simulation of an LHC-style detector experiment, capable of generating background and signal events, running a full detector response chain, and performing a blinded significance scan.

01
Physics Generation Physics

QCD dijet background via Pareto-distributed pT and falling mass spectrum. Breit-Wigner resonance signal via vectorised acceptance-rejection sampling with retry logic for narrow widths.

02
Detector Response Chain Physics

Geometric acceptance → independent reconstruction efficiency → independent trigger efficiency → dead channel masking → Gaussian energy smearing using σ/E = √[(a/√E)² + (b/E)² + c²]. All vectorised.

03
Luminosity-Scaled Histogram Key fix

Background and signal templates are scaled to expected event counts (σ × L × 10³), then Poisson-sampled bin-by-bin. This avoids the O(10¹³) array allocation bug in earlier versions while preserving correct statistical fluctuations.

04
Background Fitting Core

Flexible model a·exp(−bx) + c·xᵈ fitted via scipy.optimize.curve_fit on the central mass range (50–800 GeV), masked to bins with >5 events. χ²/ndof printed as fit quality diagnostic.

05
Significance Scan + Discovery Core

Fitted model scaled to expected_bkg events and compared to data histogram. Adjacent significant bins merged with cached-excess weighted-average mass. 5σ = Discovery, 3σ = Evidence.

06
Cover's Theorem (2D: mass + pT) Core

pT is threaded from the generator — not recomputed from mass — ensuring the two axes carry independent information. Nystroem RBF kernel projection. Separability measured by KMeans silhouette score.

Key Technical Decisions

The most consequential fix across the collider's development history was separating reconstruction efficiency from trigger efficiency into independent stochastic draws. Earlier versions multiplied them together inside a single function, causing a barrel event at high pT to be penalised three times (base efficiency × pT efficiency × 0.95 combined) rather than the intended two independent 95% and 90% passes. This reduced effective efficiency from ~72% to ~55% — a systematic error that would have made real discovery borderline impossible.

The second critical fix was ensuring the fitted background model is actually used in the significance calculation. For three iterations the model was fitted, stored, and then the code quietly fell back to the raw histogram. The fix routes find_signals() through get_background_prediction() and scales the output to expected_bkg events using the luminosity-based normalisation, not the signal-contaminated data total.

05 — Module B

Drug Discovery Engine

A molecular screening pipeline that reuses the collider's statistical core to find novel bioactive compounds. The key insight is that a molecule's predicted IC50 plays the role of "invariant mass" and the inactive-decoy prediction distribution plays the role of "background."

01
Molecular Database Chemistry

12 curated drugs with literature IC50 values, 200 systematic active variants (single-atom substitutions on validated aromatic scaffolds), 800 aliphatic inactive decoys. Total: 1,012 molecules.

02
Molecular Fingerprinting Chemistry

RDKit Morgan fingerprints via rdFingerprintGenerator (new non-deprecated API, 2048-bit) when available. Chemistry-aware structural fallback (atom counts, pharmacophore patterns, bigram substructure hashing, aromaticity ratios) otherwise. Three-stage sanitization handles valence and kekulization failures.

03
Activity Prediction Core

Random Forest Regressor trained on all molecules (not just actives). Evaluated by 5-fold cross-validation — not train-set R², which is always ~1.0. Predicts log₁₀(IC50 nM); exponentiated to nM for reporting.

04
Null Distribution from Inactives Key fix

The null distribution (mean + std of log₁₀(IC50)) is built from predicted IC50s of known inactive decoys — not the active training set. This prevents the circular statistics of earlier versions where z-scores were measured relative to a biased training mean.

05
SMILES Generation + Validation Chemistry

Candidates built from head + linker + core combinatorics over 15 validated aromatic scaffolds (benzothiophene, quinoline, carbazole, etc.). Each SMILES canonicalized and deduplicated via RDKit. Invalid/duplicate attempts counted and reported.

06
Significance + Novelty Screen Core

Z-score against inactive null. IsolationForest novelty via percentile threshold on raw anomaly scores. Discoveries tagged by both significance tier (5σ / 3σ) and novelty (novel space / known-like space).

07
Post-Processing: Ro5, Clustering, Export Chemistry

Lipinski Rule-of-Five analysis with MW distribution plot. KMeans scaffold clustering using Morgan fingerprints (new API). CSV export with embedded model metrics and timestamps. Top-10 SMILES file for docking tools.

06 — Mathematics

Shared Mathematical Framework

Energy Resolution Formula (Collider)

# Standard calorimeter resolution: σ/E = √[(a/√E)² + (b/E)² + c²]
# a = sampling term, b = noise term (GeV), c = constant term
def energy_resolution(self, E):
    sampling  = self.a / np.sqrt(E)
    noise     = self.b / E
    constant  = self.c
    return np.sqrt(sampling**2 + noise**2 + constant**2) * E

Breit-Wigner Resonance Sampling (Collider)

# Relativistic Breit-Wigner via acceptance-rejection
bw_pdf = (Γ/2) / ((m − M)**2 + (Γ/2)**2) / π
accept = np.random.random(n_trials) < (bw_pdf / bw_pdf.max())

Poisson Significance (Both Modules)

# Local significance in a single bin / single molecule
excess       = observed − expected_background
significance = excess / np.sqrt(expected_background + 1)

# 5σ  →  P(false positive) ≈ 2.87 × 10⁻⁷
# 3σ  →  P(false positive) ≈ 1.35 × 10⁻³

Drug Z-Score vs Inactive Null (Drug Module)

# Null built from INACTIVE predictions — not from active training set
null_mean, null_std = fit_null(predicted_IC50_of_inactives)

# Significance of a candidate molecule
sig = (null_mean − log10(candidate_IC50)) / null_std
# Positive sig = candidate is more active than a typical inactive

Nystroem Kernel Approximation (Both Modules)

# Avoids O(n²) exact kernel matrix — uses k landmark points instead
# Memory: O(n × k)  vs  O(n²) for full KernelPCA
nystroem = Nystroem(kernel='rbf', gamma=0.1, n_components=32)
features_hd = nystroem.fit_transform(features_scaled)
07 — Impact

Scientific Implications

The pipeline's most consequential contribution is not any individual algorithm — it is the demonstration that rigorous significance standards from experimental physics can be transplanted into biological discovery science. This matters because the two fields currently operate with radically different false-positive cultures.

The Reproducibility Crisis, Reframed

The life sciences have been grappling with a reproducibility crisis for over a decade. A landmark 2011 study found that only 11% of published preclinical cancer research could be independently reproduced. A 2012 analysis put the figure at 6 of 53 "landmark" results. By contrast, particle physics has had essentially zero notable false-discovery scandals since adopting the 5σ convention — because the convention forces the experiment itself to contain its own error budget.

The drug pipeline implements the same decision procedure: build the null from data you already have (inactive decoys), compute a z-score against that null, and report only hits that exceed a pre-registered significance threshold. This is the exact structure of a blinded LHC analysis, applied to molecular screening.

Key Insight for Biology

The 5σ threshold is not arbitrary conservatism — it is the minimum level of evidence needed to claim a discovery when you are scanning many bins simultaneously (the look-elsewhere effect). Drug screening scans thousands to millions of compounds: the look-elsewhere penalty is severe, and existing p < 0.05 screens do not account for it at all.

Computational Drug Discovery

Traditional virtual screening tests compounds against a known target structure (docking). This pipeline takes a fundamentally different approach: it learns the statistical fingerprint of activity from known data, builds a null distribution from inactives, and flags compounds that are significantly outside that null — without requiring any structural biology input. This makes it applicable to targets with no solved crystal structure, poorly characterised binding sites, and phenotypic (whole-cell) assays where the molecular target is unknown.

Anomaly Detection as First-Pass Filter

The IsolationForest novelty layer addresses a second failure mode of conventional screening: rediscovering known scaffolds. A compound that is highly active but structurally identical to a patented drug is scientifically interesting but commercially useless. Tagging candidates as novel-space vs known-like at screen time lets medicinal chemists prioritise genuinely new scaffolds before any synthesis investment is made.

Cross-Domain Methodology Transfer

Beyond drug discovery specifically, the pipeline demonstrates a general pattern: mature quantitative sciences (physics, astronomy) have developed statistical infrastructure that immature ones (biology, social science) have not yet absorbed. Cover's theorem, Nystroem approximation, and proper null-hypothesis construction from the domain's own noise floor are all tools with deep theoretical justification that were developed outside biology but apply directly to it.

The same framework has direct analogues in: materials discovery (finding novel crystal structures with desired bandgap), protein engineering (finding sequences with desired fold stability), and climate science (distinguishing anthropogenic signals from natural variability in multivariate climate data).

Current Limitations

The pipeline as released uses synthetic training data (generated active variants, aliphatic decoys). With real ChEMBL data and full Morgan fingerprints the separation will be subtler and the threshold more genuinely discriminating. This is a feature, not a bug: it makes the calibration problem explicit.

08 — Future Work

The Next Phase of Discovery

The current pipeline establishes the statistical scaffold. The next phase connects it to real physical and chemical reality at every layer of the stack.

Phase 1 — Real Data Integration

The immediate priority is replacing synthetic training data with curated public databases. The ChEMBL database contains over 2.4 million bioactive compounds with measured activities across 15,000+ targets. BindingDB adds another 2.8 million measured binding affinities. Feeding this data into the pipeline requires no architectural changes — only replacing MolecularDatabase.KNOWN_DRUGS and the variant generator with a real data loader.

# Drop-in replacement for synthetic DB
from chembl_webresource_client.new_client import new_client
target = new_client.target
activity = new_client.activity

# Fetch all IC50 data for a specific target (e.g. HIV-1 Protease)
acts = activity.filter(target_chembl_id='CHEMBL3717', 
                       standard_type='IC50')
# → feeds directly into ActivityPredictor.train()

Phase 2 — Structure-Based Docking Validation

The pipeline's significance scan identifies statistical candidates. The next validation layer is molecular docking — computationally simulating how a candidate molecule fits into the target protein's binding site. AutoDock Vina provides a free, scriptable docking engine. The pipeline's CSV output (SMILES, IC50, σ) maps directly to Vina's input format.

The natural integration is a post-screening filter: take the top 50 σ-ranked candidates, dock them against the target structure, and rank by predicted binding affinity (kcal/mol). Candidates that score well on both criteria represent the highest-confidence leads.

Phase 3 — Graph Neural Networks for Fingerprinting

Morgan fingerprints encode fixed-radius circular substructures. They are excellent for similarity searches but miss long-range electronic effects and 3D conformation. The state of the art in molecular property prediction is Message Passing Neural Networks (MPNNs) — graph networks where atoms are nodes, bonds are edges, and activity is predicted by learned message aggregation. Libraries including torch_geometric, DGL, and chemprop provide drop-in replacements for MolecularFingerprinter that dramatically improve generalisation on novel scaffolds.

# Future: replace MolecularFingerprinter with graph embedding
from chemprop.models import MoleculeModel
from chemprop.featurizers import MoleculeFeaturizer

# Produces a learned embedding rather than a fixed fingerprint
embedding = featurizer.featurize(smiles)  # → same interface as generate_fingerprint()

Phase 4 — Generative Chemistry (Active Learning Loop)

The current generator makes candidates by combinatorial scaffold decoration. The next generation replaces this with a generative model in an active learning loop: generate candidates → score them → use high-scoring candidates to condition the next generation. This is the architecture behind AlphaFold-style structure prediction and recent molecular generation systems like REINVENT (AstraZeneca), GuacaMol (BenevolentAI), and SAFE-GPT.

The pipeline's significance framework becomes the reward signal for the generative model: the generator is rewarded not merely for predicted activity, but for predicted activity that exceeds the inactive null by ≥ 5σ and occupies novel chemical space. This prevents the well-known mode-collapse failure of unconstrained generative chemistry (all outputs converging on one potent but known scaffold).

Phase 5 — Multi-Target Polypharmacology

Single-target drug design has a high attrition rate: a molecule that is highly active against one target often fails in vivo because of off-target effects, metabolism, or disease pathway redundancy. The pipeline's architecture generalises naturally to multi-target screening — run the significance scan against a panel of target activity datasets simultaneously and flag candidates that are significantly active against a desired combination (e.g., kinase A inhibitor + kinase B activator) while remaining below significance threshold against off-target panels.

Convergence Point

By Phase 4, the pipeline will have closed the loop: the same significance framework used to discover the Higgs boson will be generating, evaluating, and conditioning a molecular generative model — with a mathematically justified false-positive rate at every step. This is what production-grade AI drug discovery looks like when built on physics-grade statistics.
